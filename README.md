# Fuck P小将

作者：[吉霸猫 @0x_JBCat](https://x.com/0x_JBCat)

Chrome MV3 扩展。在 [GMGN](https://gmgn.ai) 代币 K 线页标注你自己加的畜生地址合计持仓占比。占比越高越脏。

不是 GMGN 官方产品。只读，不下单，不连钱包。名单只存在你自己的浏览器本地。

当前版本：`0.1.12`

## 装

Chrome / Edge / Brave。

1. `git clone` 本仓库，或把文件夹拷到本机
2. 打开 `chrome://extensions`，打开右上角 **开发者模式**
3. 点 **加载已解压的扩展程序**，选中能直接看到 `manifest.json` 的目录

工具栏出现 **Fuck P小将** 即装好。点图标打开畜生名单。

## 用

### 名单

点插件图标。一个框，两种贴法：

- 一行一个：`地址` 或 `地址 备注`
- 整段 JSON。认到 JSON 后可选 **并入** 或 **换成这些**（整表替换会确认）

```json
[
  {
    "address": "0x1111111111111111111111111111111111111111",
    "name": "p小将01"
  },
  {
    "address": "0x2222222222222222222222222222222222222222",
    "name": "p小将02"
  },
  {
    "address": "0x3333333333333333333333333333333333333333",
    "name": "p小将03"
  }
]
```

JSON 最后多一个逗号也能解析。`name` 写成 `note` 也认。已有地址再导入会更新备注。最多 60 个。

名单里：

- 备注可直接改，失焦保存
- 地址完整显示，点地址或「复制」拷走
- 右上角 **导出 JSON** 按同一格式复制当前名单
- **清空** 会确认

`⌘/Ctrl + Enter` 提交输入框。

### K 线片子

打开 GMGN 任意代币 K 线（`/{chain}/token/{address}`）。顶栏出现 `畜生 12%`。

数字含义：**这个币上，名单地址持仓数量之和 / 总供给**。不是人数，不是关注，不是链上 Top10。

| 显示 | 含义 |
|---|---|
| `畜生 12%` | 合计占比 |
| `畜生 0%` | 名单里的地址这个币都没仓。绿色干净档，不是没数据 |
| `畜生 —` | 名单是空的，或 GMGN 持仓接口两边都没拉到 |
| `畜生 …` | 在读 |
| `~12%` | 有地址没补全，实际可能更高 |

刷新：

| 动作 | 行为 |
|---|---|
| 刚进某个币的 K 线 | 查这一次 |
| 坐在 K 线上 | 每 8 秒补一枪 |
| 点片子上的箭头 | 立刻重拉 |
| 标签切到后台 | 自动刷新停 |

只打 GMGN 自己的持仓接口，不打第三方 RPC。

### 悬停

鼠标放在片子上，弹出有仓位的地址，按占比从高到低。左边备注（没备注用短地址），右边占比。

- 持仓 `0%` 的不出现
- 窗口露出 10 条，多的往下滚
- 鼠标可以移进浮层再滚，滚轮不带动 GMGN 页面

### 颜色

按合计占比上色。刚好卡在档位线上的数，进下一档（`2%` 算轻污，不是痕迹）。

| 合计占比 | 档位 | 字色 |
|---|---|---|
| `0%` | 干净 | `#3f8f5b` |
| `(0%, 2%)` | 痕迹 | `#8a8f3d` |
| `[2%, 5%)` | 轻污 | `#b59a1c` |
| `[5%, 10%)` | 不对 | `#c47a14` |
| `[10%, 15%)` | 脏 | `#c45a22` |
| `[15%, 20%)` | 很脏 | `#b83a32` |
| `[20%, 30%)` | 毒仓 | `#9b1d32` |
| `≥30%` | 撤离 | `#ff2d4a` |

取整：`0` → `0%`；`(0, 0.1)` → `<0.1%`；`[0.1, 10)` → 一位小数；`≥10` → 整数。

## 更新扩展

1. `git pull`（或覆盖本地文件）
2. `chrome://extensions` 点 **Fuck P小将** 的刷新。Chrome 有时死缓存图标，卸掉再加载一次
3. GMGN 代币页硬刷

不要和旧的 Beastover / Dirtover 同时开。

## 隐私

- 不连接钱包，不要求助记词或私钥
- 名单只存在 `chrome.storage.local`
- 没有账号，没有远程服务器
- 请求只发给 `gmgn.ai`
